# Avatar Uploader

VRChatアバターを登録順にビルド・アップロードするUnity Editor拡張です。シーン内の複数アバターを一覧へ追加し、既存のBlueprint IDに対して連続で更新できます。

## 主な機能

- ドラッグ＆ドロップ、またはHierarchyの選択から複数アバターを登録
- 登録順に1体ずつビルド・アップロード
- 各項目の待機・処理中・成功・失敗と結果メッセージを表示
- 失敗した項目だけを再試行
- 現在の処理が終わったところで停止
- 無効なアバタールートをビルド前に有効化し、全処理終了・停止時に元のチェック状態へ復元

アップロードでは既存の名前・公開設定・サムネイルを維持します。新規アバターの初回アップロードはVRChat SDKから行ってください。

## 必要な環境

- VRChat SDK - Avatarsを導入済みのUnityプロジェクト
- 使用するSDKに対応したUnity Editor
- VRChat SDKへのログインと、対象アバターを更新できるアカウント

このツールはSDKの `IVRCSdkAvatarBuilderApi`、`VRCApi` などを使用します。対応するUnity・SDKの具体的なバージョンは、このフォルダー内では指定していません。

## 導入

1. アバター用Unityプロジェクトの `Assets` 配下に、このフォルダーをコピーします（例：`Assets/LastMemories/AvatarUploader/`）。
2. `Editor/AvatarUploaderWindow.cs` が `Editor` フォルダー内にあることを確認します。
3. Unityのコンパイルが完了したら、上部メニューの **Tools > LastMemories > Avatar Uploader** を開きます。

## 使い方

1. 対象アバターをシーンに配置します。各ルートには `VRCAvatarDescriptor` と、既存のBlueprint IDが設定された `PipelineManager` が必要です。
2. VRChat SDKのControl Panelを開き、ログインしてBuilderを表示します。
3. Unityのビルド対象プラットフォームが意図したものになっていることを確認します。このツールは現在のビルド対象を使用します。
4. Hierarchyからアバタールートをウィンドウの枠へドロップします。Hierarchyで選択して **選択中を追加** を押すこともできます。
5. 一覧の対象と登録順を確認し、**連続アップロード（全項目）** を押します。
6. 完了後、各項目の結果を確認します。失敗した場合は原因を修正し、**失敗項目を再試行** を押します。

Project内のPrefabアセットは直接登録できません。シーン上で、`VRCAvatarDescriptor` が直接付いているGameObjectを指定してください。同じGameObjectの重複登録は無視されます。

## ボタンの動作

| ボタン | 動作 |
| --- | --- |
| 選択中を追加 | 選択中のシーン内アバターを一覧へ追加します。 |
| 削除 | 対応する項目を一覧から外します。シーンのGameObjectは削除しません。 |
| 成功項目を削除 | 成功した項目を一覧から外します。 |
| リストをクリア | 一覧を空にします。 |
| 連続アップロード（全項目） | 成功済みも含め、全項目を登録順にアップロードします。 |
| 失敗項目を再試行 | 失敗状態の項目だけを処理します。停止後に待機状態で残った項目は含みません。 |
| 現在の処理後に停止 | 停止を予約し、現在の項目の処理後に終了します。 |

## 処理中の動作・制限

- 1項目が失敗しても、次の項目の処理を続けます。
- 処理中は一覧への追加・削除を行えません。
- コンパイル中、Play移行中、Play中は開始できません。SDKがビルド・アップロード中の場合も開始を見送ります。
- 停止ボタンは進行中のSDK処理を強制キャンセルしません。ウィンドウを閉じた場合も、進行中の処理が戻った後に終了します。
- ルートの有効状態は全処理終了時にまとめて復元します。親オブジェクトは自動で有効化しないため、親が無効な場合は事前に有効にしてください。
- 複数プラットフォームへの自動切り替え、新規Blueprint IDの発行、一覧の並べ替えには対応していません。順序を変える場合は削除して追加し直してください。

## トラブルシューティング

| 状況・メッセージ | 確認すること |
| --- | --- |
| シーン内のAvatar Descriptor付きルートを指定してください | Prefabアセットではなく、シーン内のDescriptorが直接付いたGameObjectを指定します。 |
| Control Panelを開き、ログインしてBuilderを表示してください | SDKのControl PanelでログインとBuilderの表示を確認します。 |
| Blueprint IDが未設定です | SDKで初回アップロードを行い、ルートのPipeline ManagerにIDを設定します。 |
| 親オブジェクトが無効です | Hierarchyで親を有効にして再試行します。 |
| ビルド・アップロードに失敗する | 一覧のメッセージとUnity Consoleの `[Avatar Uploader]` ログ、SDK側の検証結果を確認します。 |
| 中断された、またはSDKから成功通知を受信できない | SDK側で実際のアップロード結果を確認してから、再試行するか判断します。 |

## ファイル構成

```text
AvatarUploader/
├── README.md
└── Editor/
    └── AvatarUploaderWindow.cs
```

`Editor/AvatarUploaderWindow.cs` に、ウィンドウ表示・登録時の検証・連続アップロード・状態復元の処理をまとめています。Unity Editor専用のツールです。
